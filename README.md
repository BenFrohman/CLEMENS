## Scope

The Clemens conjecture asserts that, on a general quintic threefold \(X\subset\mathbb{P}^4\), the Kontsevich moduli space \(\overline{\mathcal{M}}_{0,0}(X,d)\) (or the Hilbert scheme of curves of degree \(d\)) has no positive-dimensional component whose general point parametrizes a birational map from \(\mathbb{P}^1\).

This repository records:

- Cotterill: the strong form holds for all \(1\le d\le 11\);
- Ballico–Fontanari (2023): finiteness holds for smooth curves of degree \(d=12\);
- the logical reduction that the full conjecture is equivalent to the birational tail \(d\ge 12\).

The tail remains open. No term is supplied for the incidence-dimension statement in degrees \(\ge 12\).

## Separation

This material is kept strictly outside `BenFrohman/HODGE`. The Hodge conjecture for sextic fourfolds and the Clemens conjecture for quintic threefolds are independent open problems.
